# Sugar++ C/C++ Build Tools for VS Code

Zero-config Visual Studio style build, run, and debug tools for C/C++ using Sugar++.

## Features
- **Visual Studio Style Status Bar**: Build, Run, Debug, and Profile buttons in the bottom bar.
- **Native QuickPicks**: Select build profile (`Release`, `Debug`, etc.) and compiler (`MSVC`, `GCC`, `Clang`) with dropdowns.
- **Project Explorer Tree View**: View targets, source files, and vendor dependencies in the sidebar.
- **One-Click Debugging**: Automatic debug configuration for MSVC (`cppvsdbg`) and GCC/Clang (`cppdbg`/`lldb`).
